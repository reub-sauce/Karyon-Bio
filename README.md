# Mini-Pipeline for Discovery and Prioritization of Cell-Type-Specific Biomarkers in Human Liver Fibrosis

This repository contains a compact, reproducible R workflow for the Karyon Bio technical assessment. The pipeline uses **GSE136103** as the primary single-cell liver fibrosis discovery dataset and **GSE207310** as an optional bulk RNA-seq validation dataset. The analysis focuses on disease-relevant liver fibrosis compartments: hepatic stellate/mesenchymal/myofibroblast-like cells, macrophage/monocyte populations, and endothelial cells.

The goal is not just to run standard single-cell processing, but to produce a short, interpretable list of fibrosis-associated biomarkers and therapeutic target candidates with supporting QC, annotation, pathway, and validation evidence.

---

## Project overview

The workflow performs:

1. GEO metadata curation and local supplementary-file handling.
2. Single-cell QC, doublet filtering, normalization, dimensionality reduction, and clustering.
3. Marker-based annotation of major liver cell types and required disease-relevant compartments.
4. Fibrosis program scoring using curated gene sets and Seurat module scores.
5. Donor-aware pseudobulk differential expression in relevant cell types and cell states.
6. Pathway enrichment using ranked differential-expression statistics.
7. Optional validation using GSE207310 bulk RNA-seq expression files.
8. Rule-based biomarker prioritization and generation of final HTML reports.

# Methods and representative results

## 1. QC and preprocessing

The pipeline creates one Seurat object per GSE136103 library, calculates standard QC metrics, removes low-quality cells and likely doublets, and then merges retained cells for downstream annotation. I used sample-level QC rather than one global threshold because liver single-cell data can vary substantially by donor, enrichment fraction, and disease state.

QC metrics include:

- detected genes per cell (`nFeature_RNA`),
- total UMIs/counts per cell (`nCount_RNA`),
- mitochondrial percentage (`percent.mt`),
- hemoglobin percentage (`percent.hb`),
- doublet calls from `scDblFinder`.

The filtering is deliberately not too aggressive. Fibrotic and inflamed liver samples can contain stressed cells, activated mesenchymal cells, and macrophages with altered RNA content. The goal is to remove clear technical artifacts while preserving biologically meaningful disease-associated states.

Representative QC code:

```r
obj[["percent.mt"]] <- PercentageFeatureSet(obj, pattern = "^MT-")
obj[["percent.hb"]] <- PercentageFeatureSet(
  obj,
  features = intersect(rownames(obj), c("HBA1", "HBA2", "HBB", "HBD", "HBE1", "HBG1", "HBG2"))
)

sce <- Seurat::as.SingleCellExperiment(obj, assay = "RNA")
sce <- scDblFinder::scDblFinder(sce, samples = sce$sample_id)
obj$doublet_class <- sce$scDblFinder.class

obj <- subset(
  obj,
  subset = nFeature_RNA >= min_features &
           nFeature_RNA <= max_features &
           percent.mt <= max_percent_mt &
           doublet_class != "doublet"
)
```

The pre-filter plots show the starting distribution of detected genes, UMIs, mitochondrial signal, and hemoglobin signal across all libraries. The post-filter plots show that the retained cells have a cleaner range of QC metrics while preserving cells from both healthy and cirrhotic donors.

![Prefilter QC metrics](docs/readme_figures/qc_violin_prefilter.png)

![QC genes versus counts](docs/readme_figures/qc_scatter_nFeature_nCount.png)

![Postfilter QC metrics](docs/readme_figures/qc_violin_postfilter.png)

After QC, the pipeline normalizes counts, identifies variable features, scales the data, runs PCA, and generates UMAP embeddings. Harmony batch correction can be used for visualization/clustering only. Disease-associated differential expression is performed later using non-integrated counts aggregated at the donor/sample level.

```r
obj <- NormalizeData(obj)
obj <- FindVariableFeatures(obj, selection.method = "vst", nfeatures = 3000)
obj <- ScaleData(obj, vars.to.regress = c("percent.mt"))
obj <- RunPCA(obj, npcs = 40)
obj <- FindNeighbors(obj, dims = 1:30)
obj <- FindClusters(obj, resolution = 0.6)
obj <- RunUMAP(obj, dims = 1:30)
```

## 2. Annotation of cell types and cell compartments

Cell types are annotated using marker-based scoring and manual review of marker dot plots. I used this approach because automated labels can be brittle in diseased liver, where activated stellate cells, portal fibroblasts, endothelial remodeling states, and scar-associated macrophages can deviate from healthy reference profiles.

The annotation strategy has two levels:

1. **Major liver cell types**: hepatocytes, cholangiocytes, endothelial cells, HSC/mesenchymal cells, macrophage/monocytes, T/NK cells, B cells, plasma cells, mast cells, and cycling cells.
2. **Required disease-relevant compartments**: HSC/mesenchymal/myofibroblast-like cells, macrophage/monocyte populations, and endothelial cells.

Representative annotation logic:

```r
marker_tbl <- readr::read_csv("resources/cell_type_markers.csv")

for (ct in unique(marker_tbl$cell_type)) {
  genes <- marker_tbl$gene[marker_tbl$cell_type == ct]
  genes <- intersect(genes, rownames(obj))
  obj <- AddModuleScore(obj, features = list(genes), name = paste0("score_", ct))
}

cluster_scores <- obj@meta.data |>
  dplyr::group_by(seurat_clusters) |>
  dplyr::summarise(
    dplyr::across(dplyr::starts_with("score_"), ~ mean(.x, na.rm = TRUE)),
    .groups = "drop"
  )
```

The UMAPs show that the major liver cell types and broader compartments separate clearly, including macrophage/monocyte, endothelial, and HSC/mesenchymal compartments.

![UMAP by disease, sample, and cluster](docs/readme_figures/umap_disease_sample_cluster.png)

For example, macrophage/monocyte cells express LYZ, LST1, CD68, MS4A7 and related myeloid markers; endothelial cells express PECAM1, VWF, KDR, ENG, ACKR1, and PLVAP; HSC/mesenchymal cells express COL1A1, COL1A2, COL3A1, DCN, LUM, PDGFRB, ACTA2, TAGLN, and POSTN.

## 3. Creation of Seurat fibrosis program scores

To summarize fibrosis-relevant biology at the single-cell level, the pipeline computes module scores for curated gene programs. These are not used as the main statistical test for disease association. Instead, they help interpret cell states and prioritize mechanisms for follow-up.

The gene sets are defined in:

```text
resources/compartment_gene_sets.yml
```

The score is created with `Seurat::AddModuleScore()`. In practical terms, each cell receives a score equal to the average normalized expression of a program gene set minus the average expression of matched control genes with similar abundance. This helps reduce the effect of baseline expression differences across genes.

Representative code:

```r
gene_sets <- yaml::read_yaml("resources/compartment_gene_sets.yml")

for (program_name in names(gene_sets)) {
  genes <- intersect(unlist(gene_sets[[program_name]]), rownames(obj))
  obj <- Seurat::AddModuleScore(
    object = obj,
    features = list(genes),
    name = paste0("program_", program_name)
  )
}
```

The boxplots compare module scores across healthy and cirrhotic cells within the required compartments. Examples include activated stellate, endothelial remodeling, extracellular matrix, NOTCH/PDGF/TWEAK, and scar macrophage programs.

![Fibrosis program scores in required compartments](docs/readme_figures/cell_state_scores_required_compartments.png)

These scores are useful for biological interpretation. For formal disease-associated gene discovery, the pipeline uses donor-aware pseudobulk differential expression rather than treating every cell as an independent sample.

## 4. Donor-aware differential expression and biomarker discovery

For disease-associated genes, cells are aggregated into pseudobulk profiles by donor/sample within each annotated cell type or cell state. This avoids inflated significance from cell-level testing, where thousands of cells from the same donor would otherwise be treated as independent observations.

The core idea is:

```r
# Conceptual pseudobulk grouping
pseudobulk_id <- paste(sample_id, donor_id, disease_status, cell_type, sep = "__")

# Sum raw counts per gene within each pseudobulk group
pb_counts <- Matrix.utils::aggregate.Matrix(
  t(count_matrix),
  groupings = pseudobulk_id,
  fun = "sum"
)
pb_counts <- t(pb_counts)
```

The pipeline then uses `edgeR` for discovery DE:

```r
y <- edgeR::DGEList(counts = pb_counts, samples = pb_meta)
y <- edgeR::calcNormFactors(y)
design <- model.matrix(~ disease_status, data = pb_meta)
y <- edgeR::estimateDisp(y, design)
fit <- edgeR::glmQLFit(y, design)
res <- edgeR::glmQLFTest(fit, coef = "disease_statuscirrhotic")
```

Candidate biomarkers are then prioritized using a rule-based score that combines effect size, statistical support, compartment specificity, prevalence, pathway/mechanism support, translational features such as secreted or surface localization, and optional GSE207310 validation support.

![Top-ranked fibrosis biomarkers and targets](docs/readme_figures/ranked_biomarkers_top20.png)

## 5. Pathway analysis

Pathway analysis is performed on ranked differential-expression statistics within each disease-relevant compartment. This is important because single genes can be noisy, while pathway-level enrichment can reveal coherent mechanisms such as extracellular matrix remodeling, endothelial remodeling, translational stress, oxidative phosphorylation, or scar-associated macrophage programs.

Gene sets are pulled from MSigDB using `msigdbr`, and enrichment is run with `fgsea`:

```r
msig <- msigdbr::msigdbr(species = "Homo sapiens") |>
  dplyr::filter(gs_collection %in% c("H", "C2", "C5")) |>
  dplyr::select(gs_name, gene_symbol)

pathways <- split(msig$gene_symbol, msig$gs_name)

ranks <- de_table |>
  dplyr::filter(analysis_group == group_name) |>
  dplyr::mutate(rank_stat = sign(logFC) * -log10(PValue)) |>
  dplyr::arrange(desc(rank_stat))

rank_vec <- ranks$rank_stat
names(rank_vec) <- ranks$gene

fgsea_res <- fgsea::fgsea(
  pathways = pathways,
  stats = rank_vec,
  minSize = 10,
  maxSize = 500
)
```

The summary figure shows top enriched pathways across required compartments and cell states. HSC/mesenchymal and activated HSC/myofibroblast states show matrix and collagen-related programs, while endothelial and macrophage compartments show additional remodeling, stress, and translational signatures.

![Top enriched pathways in required disease-relevant compartments](docs/readme_figures/pathway_top_terms_by_compartment.png)

## 6. Optional GSE207310 validation

GSE207310 is used as an orthogonal bulk RNA-seq validation dataset. The parser supports per-sample `.txt.gz` files as well as combined matrices. Numeric Entrez IDs and Ensembl IDs are mapped to HGNC gene symbols before comparing validation genes to GSE136103 discovery genes.

Validation uses DESeq2 when integer-like count data are available and limma when the available expression values are normalized rather than raw counts.

Representative validation logic:

```r
# Map validation gene identifiers to symbols before overlap
mapped <- AnnotationDbi::select(
  org.Hs.eg.db,
  keys = validation_gene_ids,
  keytype = "ENTREZID",
  columns = c("SYMBOL")
)

# Count-based validation model
dds <- DESeq2::DESeqDataSetFromMatrix(
  countData = validation_counts,
  colData = validation_metadata,
  design = ~ validation_group
)
dds <- DESeq2::DESeq(dds)
validation_res <- DESeq2::results(dds)
```

The validation plots compare discovery and validation effect sizes and highlight overlap between the primary single-cell discovery results and the optional bulk RNA-seq dataset.

## Notes on interpretation

This analysis is designed as a compact discovery workflow. The strongest candidates are not simply the most significant genes. They are genes that show disease association in the appropriate cell compartment, align with known fibrosis biology, have plausible translational utility, and, when available, show supportive signal in an orthogonal validation dataset.

Examples of high-priority candidates from the final ranking include HSC/mesenchymal and endothelial remodeling markers such as **PDGFRA**, **COL1A1**, **POSTN**, **ACKR1**, **THY1**, **VWF**, and related ECM/remodeling genes. These should be treated as candidates for follow-up validation rather than final clinical biomarkers.
